# Invitación de Nora y Chloe

Versión optimizada para GitHub Pages. No necesita instalación ni compilación.

## Volver a subir

1. Descomprime el ZIP y reemplaza los archivos del sitio en la raíz del repositorio.
2. Conserva index.html, site.css, los cuatro archivos JavaScript y la carpeta assets en el mismo nivel.
3. Los antiguos estilos.css y carrusel.css, las carpetas de referencias y las imágenes de versiones anteriores ya no forman parte de esta versión.
4. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
5. Tras publicar, recarga la página para evitar ver archivos guardados por el navegador.

## Contenido

- index.html: estructura y pantalla de carga.
- site.css: estilos unificados y depurados.
- app.js: sobre, música, carrusel y cuenta regresiva.
- carga.js: preparación de imágenes y fuentes del inicio.
- confirmacion.js: confirmación personalizada SI/NO.
- datos.js: nombres, fecha, ubicaciones, fotos, música y URL de Apps Script.
- assets/: únicamente los recursos referenciados por esta versión.
- Confirmacion-AppsScript.gs: copia del servidor de confirmaciones. No se ejecuta en GitHub Pages ni hace falta volver a desplegarlo para esta limpieza.

## Cambios de optimización

Se unificaron los estilos, se retiraron reglas y animaciones superadas y código de movimiento que ya no correspondía al diseño actual. Se incluyen ocho fotos y los recursos activos, sin referencias ni variantes de imágenes descartadas. La foto de mayor tamaño se redujo para uso web conservando su proporción. Los originales quedan en la carpeta de trabajo anterior.

Verificaciones: sintaxis JavaScript, referencias locales, identificadores únicos, fechas, ocho fotos y navegación circular completa mediante simulación. Se conserva el giro de 8 segundos y la pausa de 5.5 segundos; el cambio automático empieza al entrar la galería en pantalla. No se enviaron confirmaciones reales. La vista previa visual automática no estuvo disponible en este entorno.
